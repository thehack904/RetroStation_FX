Manual sync instructions

Ensure the selected channel's HLS Segmenter session has stopped before running this command. Closing a player may leave a session active until its idle timeout. Do not interrupt other viewers.

Select a channel above.

Run on the ErsatzTV host (or a machine that can reach ErsatzTV), then reopen the Graphics Elements dropdown to verify. The one-second timeout is expected and does not confirm the database refresh.

How to use this Style in ErsatzTV
  1. Save the FX Style in RSFX.
  2. Choose Save + Sync to ErsatzTV to request graphics registration. A new HLS Segmenter session triggers the refresh.
  3. Reload or reopen the ErsatzTV Schedule Items editor.
  4. Edit the desired Program Schedule Item.
  5. Select the RSFX Style under Graphics Elements and save.

RSFX Styles are channel-independent. Program Schedule Item assignment remains managed by ErsatzTV.
